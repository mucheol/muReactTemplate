# muReactTemplate

React + TypeScript 기반 풀스택 포트폴리오 템플릿 프로젝트입니다.

🔗 **Live Demo:** [https://mu-react-template.vercel.app](https://mu-react-template.vercel.app)

---

## 기술 스택

| 구분 | 기술 |
|------|------|
| **Frontend** | React, TypeScript |
| **Backend** | Node.js, TypeScript |
| **배포** | Vercel |

---

## 프로젝트 구조

```
muReactTemplate/
├── frontend/          # React 프론트엔드
├── backend/           # Node.js 백엔드
├── .vscode/           # VS Code 설정
├── CLAUDE.md          # Claude Code 설정
├── DEPLOYMENT.md      # 배포 가이드
├── package.json       # 루트 패키지 설정
└── package-lock.json
```

---

## 시작하기

### 설치

```bash
git clone https://github.com/mucheol/muReactTemplate.git
cd muReactTemplate
npm install
```

### 실행

```bash
# 프론트엔드 개발 서버
cd frontend
npm run dev

# 백엔드 개발 서버
cd backend
npm run dev
```
